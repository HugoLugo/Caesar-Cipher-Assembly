# Caesar Cipher in Assembly

A Caesar Cipher encryption and decryption program developed in Assembly language as the final project for the Programming Paradigms course.

## About the Project

The Caesar Cipher is a classical encryption technique that shifts letters in the alphabet by a specified number of positions.

## Technologies

- Assembly Language
- NASM
- Visual Studio Code

## Features

- Encrypt text using the Caesar Cipher
- Decrypt encrypted messages
- Support configurable character shifts

## Academic Context

Developed as a final project for the Programming Paradigms course at the University of Pécs.
